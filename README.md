# Smart City Waste Management System - Somandepalli

A web-based waste management system for Somandepalli village, featuring real-time bin monitoring, user authentication, and interactive maps.

## Features

- Real-time waste bin monitoring
- Interactive map with Leaflet integration
- User authentication system
- Responsive design
- Location-specific features for Somandepalli village

## Setup and Deployment

1. Clone the repository:
```bash
git clone <your-repository-url>
cd <repository-name>
```

2. Install dependencies:
```bash
cd frontend
npm install
```

3. For local development:
```bash
npm run dev
```

4. To deploy to GitHub Pages:
```bash
npm run deploy
```

## Local Development

The application will be available at `http://localhost:3000` when running locally.

## Accessing the Live Website

Once deployed, the website will be available at:
`https://<your-github-username>.github.io/<repository-name>/`
